# Bangladesh eBook Library — Android App (Expo / React Native)

An offline-first Android mobile reader for **Bangladesh's Biggest eBook Library** (`22,166+` Bangla, English & Arabic eBooks and NCTB Class 1–12 textbooks).

## Direct APK Download

- **Android APK:** [`Bangladesh-eBook-Library.apk`](./Bangladesh-eBook-Library.apk)
- **Web App Showcase:** [App Promo Landing Page](https://salman-anik.github.io/Bangladesh-Biggest-eBook-Library/)
- **Web Online Library:** [Browse Online](https://salman-anik.github.io/Bangladesh-Biggest-eBook-Library/library.html)

## Key Features

- **100% Offline Catalog & Book Reading:** Automatically caches all `22,166+` books on sync and supports 1-tap offline saving for individual books or entire category/author sections.
- **Quick Class 1–12 Navigation & 3D Category Icons:** Jump directly into Pre-Primary through Class 12 NCTB books, University courses, Madrasa collections, or Bangla literature.
- **Author Portraits & Illustrated Editorial Avatars:** Displays `131+` Google Drive–hosted author portraits with Pinterest-style illustrated editorial avatar fallbacks.
- **Full-Screen Reader Lock & Side Scroll Rail:** Fast right-edge drag scrollbar for jumping across pages plus a Lock button that prevents accidental taps while keeping scrolling active.
- **5 Book-Inspired Themes & Dark / White Modes:** Espresso, Matcha, Midnight, Sepia, and Rosewood themes with Small / Normal / Large font scaling and live app storage tracking.

## Run From Source

```bash
npm install
npx expo start
```
