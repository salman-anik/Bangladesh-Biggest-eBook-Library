# 📚 Library Visualizer (`visualize/`)

An interactive **Next.js (App Router + Tailwind CSS)** web application to explore the 25-category bilingual `BANGLA_LIBRARY` folder tree, search books across **Title, Author, Publication, Category, and Subfolder**, preview books inline, and download directly from Google Drive.

## Running Locally

```bash
cd visualize
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
npm run start
```
